# VRChat's default colours

Measured 2026-10-15 from vrchat.com (signed in, a public group event page and the calendar), by
reading the colours the page actually draws. VRChat publishes no colour guide or press kit with hex
values; a web search found none (only a third-party brand scraper, unconfirmed).

## Website (vrchat.com), measured

| Use | Hex |
|---|---|
| Page background | `#0E1013` |
| Panel (Date and Time box) | `#181B1F` |
| Card (Details, About This Event) | `#252A30` |
| Borders, calendar grid | `#2D363F` |
| Title band over the picture | `#111111` at 90% |
| Sidebar and buttons (dark teal) | `#07242B` |
| Teal, darker (calendar events, pressed buttons) | `#064B5C` |
| Teal, links | `#0E9BB1` |
| Teal, bright (accents) | `#1FD1ED` |
| Teal, light (sidebar text) | `#6AE3F9` |
| Main text | `#FFFFFF`, `#F8F9FA` |
| Muted text | `#9C9C9C`, `#696969` |
| Danger red | `#EE5454` |
| Category tag | `#FFFFFF` background, `#252A30` text, 16px bold, 6px corners, 0 8px padding |

Trust rank colours, from the site's own CSS variables: visitor `#CCCCCC`, new user `#1778FF`,
user `#2BCF5C`, known `#FF7B42`, trusted `#8143E6`, admin `#B52626`.

## In game

Not measured. The in-game menu colours can be changed by VRChat Plus members (six colours), so a
screenshot from a changed account (red, for example) is not the default. The default is teal; until
someone measures it on an account with no colours changed, the website teal above stands in for it.
