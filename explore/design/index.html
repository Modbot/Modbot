Setting up Modbot

Modbot runs as one service plus one PostgreSQL database. It needs exactly two environment variables — PORT and DATABASE_URL — and everything else is configured through a setup wizard the first time you open it.

The serif is for reading. The interface never uses it, because the interface is for scanning.
