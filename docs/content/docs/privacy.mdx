Modbot's privacy policy is **[modbot.co/privacy](https://modbot.co/privacy)**. The same document is
[`PRIVACY_POLICY.md`](https://github.com/Modbot/Modbot/blob/master/PRIVACY_POLICY.md) in the Modbot
repository, and that file is what the page is built from.

It answers two sets of questions: one for people in a group whose moderators run Modbot, and one for
operators running it. It is not repeated here, so there is only ever one version of it.

## What a self-hosted Modbot sends to Modbot Cloud

**Modbot sends its own log to Modbot Cloud by default.** This is the one thing a Modbot you run
yourself sends anywhere the project operates. The facts about your members — bans, joins, messages,
case files, evidence — never leave your own database.

1. **What is sent is the log, unchanged.** The same lines you can read on the **Logs** page:
   Information level and above, with the message, the time, which part of Modbot wrote it, the
   exception if there was one, and the values the line carried. Not warnings only, and not
   anonymised. If you set `LOG_LEVEL` lower, the extra detail is sent too — the lines for every
   request answered and every database query run. Setting it back stops that.
2. **Log lines can name a member.** They are Modbot talking about its own work, and that work is
   about people — "banned usr_…", "read 40 members of grp_…". A VRChat user id or a display name can
   appear in a line.
3. **Requests Modbot sends to VRChat and Discord are not included.** Those are a separate stream and
   are never sent.
4. **Credentials are taken out before a line is stored at all**, so they are never sent: a property
   whose name looks like a password, a secret, a token, an API key, an authorisation header or a
   cookie is replaced, and a bearer token or a connection-string password written into a message is
   removed from the text.
5. **You can turn it off**, in **Settings**, **Host & Database**, **Logs**, or by setting
   `MODBOT_CLOUD_DISABLED` on the server. Nothing is sent after that, and nothing else about Modbot
   changes.
6. **Your deployment is identified by a random id**, made the first time it sends. It is not your
   group, your domain or your name.
7. **Cloud keeps them 180 days** by default, and only a Modbot Cloud administrator can read them.
   See [Logs](/self-hosting/logs).

## What a self-hosted Modbot stores

A Modbot you run yourself keeps its data in your own PostgreSQL database, and evidence files
wherever you choose to store them. These pages describe what is kept and how it is protected:

- [Data and retention](/self-hosting/data-retention): the kinds of records Modbot keeps (moderation
  facts, presence facts such as instance joins and avatar changes, stored Discord messages, daily
  totals, case files and evidence), how long each is kept, and how to set a retention window. By
  default nothing is deleted.
- [Security](/security): how passwords, sessions, stored secrets, API keys, webhooks, evidence and
  companion tokens are protected, and what Modbot sends to VRChat.
- [AI settings](/ai/settings#what-is-sent-to-the-provider): with AI switched on, text your members
  wrote — Discord messages, VRChat display names, bios, status lines and pronouns — is sent to the AI
  provider the operator chooses, and that page lists exactly what goes where.

## What leaves your server

- [Open instances](/self-hosting/open-instances): the one thing a Modbot server sends to Modbot Cloud today —
  which of your group's instances anyone can join — and how to turn it off.
- [Environment variables](/self-hosting/environment-variables): `MODBOT_CLOUD_DISABLED`, which stops
  your server talking to Modbot Cloud at all.
- [Companion settings](/companion/settings): what the Windows client sends to Modbot Cloud
  from a moderator's own PC, and how that person turns it off.

## What stays on a moderator's own PC

- [Clips](/companion/clips): the companion can keep the last two to five minutes of **VRChat's own
  window** while VRChat is running, so a moderator can save those minutes as a video file. It is
  **off unless that person switches it on**, it records **no sound at all**, it records nothing
  while VRChat is not running, it records nothing outside VRChat's window, and **the recording
  never leaves their PC** — not to your server, not to Modbot Cloud. There is no upload path in the
  client. A saved clip becomes evidence on a case only if they choose that file in a browser, the
  same as any other attachment.
