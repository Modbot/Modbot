The **Discord members** page lists the people in your Discord server, as the bot sees them. It sits
in the sidebar just below **Members**, which is your VRChat group's list. They are separate lists
because most people are in one place and not the other, and most never
[link their accounts](/discord/account-linking).

The page needs **See members**. The bot must be set up and connected
([Setting up the bot](/discord/bot-setup)).

## The list

Above the list, Modbot says when it last read the member list and how many people are in the
server. Instead, you may see:

- **No Discord server set.** — no **Guild id** is saved on the **Bot** card.
- **The Discord member list has not been read yet.** — the bot has not read the full list. Until it
  has, the list only holds people the bot has seen some other way. Reading the list needs the
  **Server Members Intent** (see [Intents the bot asks for](/discord/bot-setup#intents-the-bot-asks-for)).

### Search and filters

Filters are chips above the list, added with **Filter** (or `f`); they work the way they do on
[Members](/moderation/members-and-bans#search-filters-and-sorting). Capital letters, accents and fancy lettering do not
matter in the search (see [Names](/moderation/names)).

| Filter | Values |
|---|---|
| **Role** | Any of your server's roles, each with how many people hold it. **Is not** leaves those people out. |
| **Has a role** | **Yes** or **No**. |
| **Status** | **In server** (the default) or **Left**. Remove the chip for both. |
| **VRChat** | **Linked** or **Not linked**, by whether the person has linked a VRChat account. Only offered to people with **See profiles**. |
| **Bot**, **Pending**, **Timed out**, **Boosting** | **Yes** or **No**. |
| **Joined** | A day, or a stretch of days. |

**Search by name or id** matches the server nickname, the Discord display name, the username and
the user id. **Sort** is **Newest joiner first**, **Oldest joiner first** or **By name**.

The number of people matching is shown on the right, 50 to a page, with the page numbers at the
bottom. The page you are on is part of the address, so the link you copy opens on the page you are
looking at and Back undoes a page turn. `j` and `k` move down and up the rows, `Enter` opens the
selected person, `/` goes to the search box, and `g` then `d` opens this page from anywhere.

### Columns

| Column | What it shows |
|---|---|
| **Person** | Picture and the name the server shows: nickname, else display name, else username. Bots are marked **bot**. |
| **Username** | The Discord username. |
| **Roles** | The Discord roles they hold. |
| **Joined** | When they joined the server. |
| **Left** | When the bot saw them leave. Only shown when **Status** is **Left** or **All**. People who left are greyed out. |
| **Timed out until** | When a timeout ends, if they are timed out now. |
| **VRChat** | The VRChat account they linked, if any. Click it to open that VRChat person's popup. Only shown to people with **See profiles**. |

Click a row to open the person popup.

## The person popup, from a Discord account

Clicking a Discord name opens the **Person** popup — the same popup a VRChat name opens. Where the
two accounts are linked, it shows both, and their Modbot account too if they have one. See
[Popups](/moderation/popups). Discord names are clickable everywhere in Modbot: an audit log entry,
**My Server**, the **Discord** card in a person's popup.

The parts below are the Discord ones. There is no case files tab for somebody with no VRChat
account, because case files are written for VRChat bans.

### Left side

**Who they are in the server** (needs **See members**), when there is no VRChat account to show
instead:

- picture, server name, Discord display name and `@username`;
- marks: **In server** or **Left**, **Bot**, **Pending** (they have not passed the server's
  membership screening yet) and **Timed out**.

If the bot never saw the person in the server, it says **Not seen in the server.** This happens for
someone named in an event who was never a member.

The dates and roles are on the **Discord** tab, under **Details**.

**Discord** card (needs **See profiles**): the Discord account, and — when the two accounts proved
a link — when they linked, the roles Modbot gave and, for people with **Manage Discord links**,
**Unlink** (see [Unlinking](/discord/account-linking#unlinking)).

### Tabs

These are the Discord tabs. The popup also has the VRChat and Modbot account ones when there is an
account behind them; [Popups](/moderation/popups) lists them all.

| Tab | Needs | What it shows |
|---|---|---|
| **Overview** | **See the audit log** for the entries, **See profiles** for the figures | The newest 8 events about any of this person's accounts. |
| **Logs** | **See the audit log** or **See the operational log** | The latest 50 events about any of this person's accounts or done by them, newest first, each saying which account it came from. You see the kinds of event your permissions allow in the [audit log](/moderation/audit-log). |
| **Discord** | **See members** | **Details** (**Joined**, **Left**, **Timed out until** and **Boosting since** when they apply, and **Roles**), then joins, leaves, nickname changes, roles given and taken, bans, kicks, timeouts and account links, newest first. |
| **Messages** | **Read Discord messages** | Everything the person wrote that Modbot has stored, deleted messages included. See [Who can read messages](/discord/messages-and-my-server#who-can-read-messages). |
| **Metrics** | **See profiles** | Their activity, below, under **Time in world** if they have a VRChat account too. |
| **JSON** | **See members** for the member record, **See profiles** for the activity counts | The stored records as the API answers them, with a copy button. |

A tab is only there when there is an account behind it and you hold its permission. **Logs** is
always there, but only loads for someone who can see the audit log.

### Metrics

- **Activity** — **Messages, 30 days**, **Voice, 30 days**, **Messages, all time**,
  **Voice, all time**, **First seen** (when Modbot first saw them in the server) and **Joined**.
- **Messages per day** and **Voice minutes per day** — each of the last 30 days.
- **Joined and left** — each time they joined or left the server that Modbot still has on record.
  When Modbot only found out afterwards, for example while the bot was offline, it shows the window
  the change happened in.

The counts come from Modbot's daily totals, so **all time** can go back further than the stored
messages do.
